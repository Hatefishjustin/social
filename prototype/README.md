# 测评中心轮盘原型

这是「心理测评中心」轮盘的交互原型，用于保留视觉与手感参考；正式页面已迁到仓库根目录的 `assess.html`。

- 文件：`assess-wheel.html`
- 正式页：`../assess.html`（轮盘、翻转详情、登录头像、测评记录抽屉）
- 状态：原型保留；正式页已接入，S14 已迁移、已提交并部署（线上 commit `a8eb650`）
- 依赖：无。纯 HTML/CSS/JS，直接双击打开即可预览（默认显示空状态）。

## 数据来源（不再是写死的模拟卡片）

卡片数量完全由数据决定，代码里没有固定 12 条。

| 打开方式 | 数据来源 | 结果 |
|----------|----------|------|
| `/prototype/assess-wheel.html` | `GET /api/quizzes` | 线上/本地有已发布测评就显示；没有就显示「还没有测评」 |
| `/prototype/assess-wheel.html?demo=1` | 根目录 `demo-quizzes.js` | 用 12 条演示数据查看完整效果 |
| `/prototype/assess-wheel.html?demo=1&start=6` | 同上，并把第 7 条转到中心 | 用于检查任意卡片在任意位置的表现 |

接口与管理方式见 [`docs/测评目录接口.md`](../docs/测评目录接口.md)。

- `status = 'published'` 的记录才会出现在轮盘。
- 上传 1 条就 1 张卡，上传 30 条就 30 张卡。
- 数量多时只渲染中心附近几张，拖动仍按总数无限循环。
- 没有任何已发布记录时，隐藏轮盘与页码，显示空状态，不出现假卡片。

## 当前设计

- 桌面：轮盘圆心偏右，只露上半圈，可见 5 张卡，中心卡放大。
- 手机：圆心在屏幕右侧外，只露左半弧，可见 5 张卡，中心卡位于屏宽约 62%，上下滑动切换。
- 交互：拖动跟手、惯性、吸附回弹；点中心卡进入，点侧卡先转到中间；方向键/Enter/滚轮/圆点；尊重 `prefers-reduced-motion`。
- 卡片：杂志式字阶（分类/编号、标题、dek、meta、CTA 用细线分隔），近不透明深色玻璃，顶部镜面高光与斜向反光；侧卡用大号浅色序号填充留白。
- 详情：点中心卡后卡片从原位放大、翻转到屏幕中心；背面是编辑式详情（题数/时长/人数、三条「会帮你看清」、你会得到什么、返回/开始）。
- 关闭：从详情那一面继续翻转 360°，由打开时那张卡的正面接上并落回原位；中途关闭则直接翻回正面。
- 视觉：沿用站点色板；四角轻微压暗、背后紫色光晕、同心副环、微尘、底部地面光；标题颜色保持 `--text-primary` 不变。
- 降级：无 JS 时显示普通列表。

## 本地预览

直接打开 `assess-wheel.html` 只会看到空状态（因为没有 `/api/quizzes`）。要看完整轮盘：

```
http://127.0.0.1:8788/prototype/assess-wheel.html?demo=1
```

若需要 HTTP 方式：

```bash
# NAS / Linux
python3 -m http.server 8788

# Windows（有 Python 时）
python -m http.server 8788
```

然后访问上面的地址。
