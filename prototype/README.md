# 测评中心轮盘原型

这是「心理测评中心」入口页的交互原型，用来在正式接入前确认视觉与手感。

- 文件：`assess-wheel.html`
- 状态：**原型，未接入正式页面，未上线**
- 依赖：无。纯 HTML/CSS/JS，直接双击打开即可预览。

## 当前设计

- 8 个测试入口：深度匹配测评（41 题）、依恋类型、五种爱之语、大五人格、关系价值观、冲突处理风格、校园角色、社交能量。
- 桌面：轮盘圆心偏右，只露上半圈，可见 5 张卡，中心卡放大。
- 手机：圆心在屏幕右侧外，只露左半弧，可见 3 张卡，中心卡位于屏宽约 62%，上下滑动切换。
- 交互：拖动跟手、惯性、吸附回弹；点中心卡进入，点侧卡先转到中间；方向键/Enter/滚轮/圆点；尊重 `prefers-reduced-motion`。
- 视觉：沿用站点色板；四角轻微压暗、背后紫色光晕、同心副环、微尘、底部地面光；标题颜色保持 `--text-primary` 不变。
- 降级：无 JS 时显示普通列表。

## 本地预览

直接打开 `assess-wheel.html` 即可。若需要 HTTP 方式：

```bash
# NAS / Linux
python3 -m http.server 8788

# Windows（有 Python 时）
python -m http.server 8788
```

然后访问 `http://127.0.0.1:8788/prototype/assess-wheel.html`。
